# KoMaster

> An in-progress deep reinforcement learning Go engine trained to beat a 6-dan player — built from scratch using AlphaGo Zero-style architecture, KataGo as a training opponent, and a custom C-accelerated board engine. Reached 1~2 dan level.

---

## What this is

KoMaster is a personal research project to see how close a self-trained Go AI can get to beating a 6-dan human player starting from zero. No pretrained weights, no shortcuts — just supervised learning on professional games followed by reinforcement learning against KataGo (a superhuman Go engine).

The target: beat Jonathan Hsiao, a 6-dan Go player.

---

## Architecture

### Neural network
AlphaGo Zero-style dual-headed network implemented in PyTorch:

- **Input:** 17-plane representation (8 history planes per color + color-to-play)
- **Backbone:** Convolutional input layer → N residual blocks with Squeeze-and-Excitation attention
- **Policy head:** 362 outputs (361 board positions + pass)
- **Value head:** Global Average Pooling → scalar win probability ∈ [-1, 1]

Three model sizes available:

| Size | Channels | Blocks | Params | Target strength |
|------|----------|--------|--------|-----------------|
| Small | 128 | 6 | ~3M | Beginner–SDK |
| Medium | 160 | 10 | ~7M | SDK–low dan |
| Large | 192 | 12 | ~12M | Dan-level |

### MCTS
Batched Monte Carlo Tree Search with GPU inference:

- PUCT selection with Dirichlet noise at root
- Batched leaf evaluation (32 positions per GPU call)
- Resignation detection to terminate hopeless games early
- Zobrist hashing for O(1) state identity

### Board engine
Custom C extension (`go_board.c`) with Union-Find group tracking:

- **`is_legal_move`:** O(4) — constant time via incremental liberty counts
- **`get_legal_moves`:** Single C call, no Python loop over 361 squares
- **`copy()`:** Single `memcpy` of the board struct (~8KB)
- **26x faster** than pure Python BFS implementation

## Training pipeline

### Phase 1 — Supervised learning
Pre-train on the FoxQ elite 7d+ dataset (professional games) to learn opening theory, basic shape, and move patterns before any self-play begins.

### Phase 2 — Reinforcement learning
Mixed training combining three data sources:

```
Iterations 1–10:   70% expert data  + 30% self-play   (value head stabilization)
Iterations 11–25:  60% expert data  + 40% self-play   (transition)
Iterations 26–100: 50% expert data  + 50% self-play   (balanced learning)
```

Games are generated by playing the current model against itself with MCTS. KataGo integration is available for playing against a superhuman opponent instead of pure self-play, which accelerates learning by providing stronger gradient signal.

### Key training decisions
- **Adaptive expert mixing** prevents value head collapse — pure self-play targets from a weak model are too noisy
- **Adaptive learning rate** reduces at iterations 11 and 26 as the model transitions from imitation to self-improvement
- **Resignation disabled early** to avoid the death spiral where a collapsing value head causes games to balloon to 300+ moves, degrading data quality and slowing training by 3-5x
- **Separate expert replay buffer** (50k samples) kept in memory throughout RL for efficient mixing

## Setup

### Requirements
- Linux (C extension must be compiled on the target machine)
- Python 3.9+
- CUDA-capable GPU (training on CPU is impractically slow)
- GCC

### Install

```bash
git clone https://github.com/Jonathanhsiao123/KoMaster
cd KoMaster
pip install -r requirements.txt

# Build the C board extension — must be run on the machine that will train
python setup.py build_ext --inplace
```

### On a university cluster (module-based)

```bash
source /path/to/miniconda3/bin/activate
conda activate goai
python setup.py build_ext --inplace
```

## Training

```bash
python train_gpu.py
```

Resumes automatically from `checkpoints/model_final.pt` if it exists. Milestone checkpoints saved at iterations 3, 10, 25, 50, 75, 100.

Key hyperparameters (bottom of `train_gpu.py`):

```python
train_from_scratch(
    foxq_dataset_path="foxq_elite_7d_plus.pkl",
    pretrain_epochs=25,
    iterations=100,
    games_per_iter=20,
    mcts_sims=400,
    batch_size=256,
    learning_rate=0.0001,
    resign_enabled=False,   # enable after value head stabilizes
)
```

## Motivation

Go is the hardest classical board game. A 6-dan player represents roughly the top 0.1% of serious players — strong enough to immediately punish any weakness in shape, reading, or strategy. The goal of this project is to reach that level through the same approach DeepMind used: learn from humans first, then surpass them through self-play.

The difference is doing it on one GPU instead of thousands.
